# Azure SQL and database administration

**Environment:** Azure Portal, Azure SQL, SQL virtual machines, SSMS, Azure Data Studio, PowerShell, and related Azure services in a training lab. This project page summarizes my lab notes.

## Goal
Deploy and administer databases while practicing security, monitoring, backup, and recovery.

## Work completed
- Created Azure SQL databases and SQL VM environments, along with resource groups and storage.
- Practiced MySQL, PostgreSQL, serverless SQL, hyperscale SQL, and elastic pool scenarios.
- Configured firewall rules, access management, data masking, auditing, and monitoring alerts.
- Used SSMS and Azure Data Studio for schema administration, queries, indexing, and performance analysis.
- Practiced backup/restore, geo-replication, failover, migration, and disaster recovery scenarios.
- Used PowerShell, ARM templates, blob storage, and automation runbooks for resource management exercises.

## Validation recorded in my notes
The notes report backup validation, restore and failover exercises, and query troubleshooting. They do not contain a sanitized schema, deployment template, query plan, or measured recovery time.
